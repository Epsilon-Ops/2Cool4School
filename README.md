# 2Cool4School

Plateforme personnelle d'apprentissage universitaire.

## Objectifs

- Comprendre et mémoriser durablement.
- Pratiquer avec des exercices et des examens blancs.
- Suivre sa maîtrise réelle des compétences.

## Stack prévue

- Frontend : React, TypeScript, Vite
- Backend : Python, FastAPI
- Base de données : SQLite
- Contenus : Markdown et YAML
